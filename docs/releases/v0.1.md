# Codex Switcheroo v0.1

First release of the terminal account picker for the ChatGPT desktop app on
Linux and Windows.

## Downloads and optional desktop icon

Choose your operating system under **Assets**:

| Platform | Download | Setup command |
| --- | --- | --- |
| Linux / Fedora | `codex-switcheroo-v0.1-linux.tar.gz` | `bash setup-linux.sh` |
| Windows | `codex-switcheroo-v0.1-windows.zip` | `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1` |

Extract the download into a permanent folder, then run the setup command in that
folder. Install **Python 3.10 or newer** and the **ChatGPT desktop app** first.
Internet access is needed to install Python dependencies from PyPI. These packages
contain Python source, not standalone executables; they do not bundle ChatGPT.

**Both setup scripts ask whether to include a desktop icon.** Enter `y` to add
one, or press Enter to skip it. Linux also adds an application menu entry when
you choose the icon; GNOME may require **Allow Launching** or use of its app menu.
Windows creates a per-user `.lnk` shortcut opening the picker in a console window.
No administrator access is needed for shortcuts.

To choose explicitly:

```bash
# Linux: include or skip the desktop icon
bash setup-linux.sh --desktop-icon
bash setup-linux.sh --no-desktop-icon
```

```powershell
# Windows: include or skip the desktop icon
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1 -DesktopIcon
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup-windows.ps1 -NoDesktopIcon
```

Run one setup command for your preferred option. Keep the extracted folder in
place so the shortcut continues working. You can add a shortcut later using
`python3 install-desktop.py` on Linux or
`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install-desktop.ps1`
on Windows. The PowerShell policy option affects only that process.

Start without a shortcut using `bash switcheroo.sh` on Linux or
`.\.venv\Scripts\python.exe .\switcheroo.py` on Windows. If app discovery fails,
use `init --app PATH` as described in the included README.

## Features

- Browser sign-in and isolated local profiles for multiple accounts and workspaces.
- Separate choices for workspaces sharing an email, with persistent editable labels.
- Visible-window indicators, account activation, and automatic refresh after opening.
- Commands to quit one or all account windows, remove saved entries while keeping
  local data, and view help. Quitting the picker leaves account windows running.
- Linux Docker container table and rootless user-service status.
- Optional desktop shortcuts for Linux and Windows.

## Validation and limitations

Release publication requires automated tests on Linux and Windows with Python
3.10 and 3.13. Tests use fake accounts and mocked app processes. Live browser
authentication, account isolation, login persistence, and Windows Store launch
compatibility still require the manual checks in `docs/VALIDATION.md`.
Desktop profile isolation depends on internal app settings and remains experimental.
Native Wayland window detection may be unavailable; XWayland is supported.

Download a newer release to update an archive installation. Automatic Git updates
in the Linux launcher apply only to cloned checkouts. `SHA256SUMS` contains hashes
of the two platform packages. Runtime account state and credentials are excluded.
